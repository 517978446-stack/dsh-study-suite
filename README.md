# dsh-study-suite

DeepSeek Harness 的「学习助手」面板：**课程 / 英中互译 / 语音纪要 / AI 率自查**，四合一。
绝大部分能力在本机运行，断网可用。

> ⚠️ 本仓库**只包含面板**（约 90KB JS）。翻译、语音、检测依赖一个本地 Python 服务，
> 需要另外安装 —— 见下方「安装本地服务」。

## 学期周次

面板顶部可以设置**开学日期**（默认 `2026-09-28`），之后：

- 顶部显示「第 N 周」
- 课程动态里凡是写着 `Week 6` 的条目，会自动标上对应日期区间，例如 `Week 6 [11/2–11/8]`
- 已过去的周次会变淡并标注「已过」

## 课程待办

面板里有一张「课程待办」卡片，数据来自本地服务的 `/plan` 接口（存在 `plan.json`）。
勾选状态会写回服务端，换设备打开也一样。

每条待办带两个按钮：
- **查看作业说明**：由本地服务 `/file` 读取你电脑里的作业文件（PDF 直接在浏览器里打开）
- **打开课程**：跳到对应的 CN 课程页

安全限制：`/file` 只接受来自 `127.6.0.1` 的请求，且只允许家目录下的文档类型。

## 界面结构

四个标签：**课程 / 课表 / 翻译 / 检测**。

- 课程：课程清单（每行可展开章节、带周次日期）、课程待办、今日任务、复习卡片
- 课表：本周课程，今天高亮
- 翻译：文档（中英对照）、对话、语音
- 检测：AI 率自查

## 功能

| 模块 | 能力 |
|---|---|
| 课程 | CN 课程清单、章节与作业、课程动态（走 API，不用开浏览器） |
| 翻译 | 文档/论文整段翻译，**中英对照**（英文在上、中文在下），快速/精准双引擎 |
| 语音 | 录音转写、连续听写、说话人 A/B 分离、自动生成课堂纪要 |
| 检测 | AI 率自查：txt / docx / pdf / 扫描版 PDF / 图片（macOS） |

## 安装

### 1. 面板

```
设置 → 插件 → 从文件夹安装 → 选择本目录
```

或者（支持来源安装的版本）：

```bash
dsh plugin add github:<owner>/dsh-study-suite
npm i dsh-study-suite@3.7.0   # 若已发布到 npm
```

### 2. 本地服务（必需）

面板本身不含模型和推理代码。**本地服务包（`study-suite-3.7.0-*.zip`）请直接向作者索取**，
解压后按里面的 README 跑安装脚本：

- macOS：`./install.sh`（最小约 200MB）
- Windows：`powershell -ExecutionPolicy Bypass -File install.ps1`

装完服务监听 `127.6.0.1:8791`，面板就能连上。

## 关于 AI 率检测

本地启发式估算，**不是** Turnitin / GPTZero 的判定结果，不能作为学术不端证据。
面板内已有同样的免责声明。

## 自检

```bash
python3 service/smoke.py        # 12 项接口检查（装好后在安装目录里跑）
```

Windows 上还有两个脚本：`check-win.ps1`（装之前查环境）、`doctor.ps1`（装之后查 11 项）。
装完最快的验证是 `python %USERPROFILE%\.dsh-study-suite\smoke.py`。

## 隐私

- 插件代码里不含任何个人数据：课程清单、待办、课表都存在**你自己电脑**上
- 服务只监听 `127.6.0.1`，不对外网发起请求（CN 抓取除外，用的是你自己的登录态）
- 上课录像、翻译、检测全部在本机完成，不上传
